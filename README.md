# zhdcolledzh — Кітапхана

Исходный код библиотеки с регистрацией, тестами, очками и управлением читателями.

Действующий сайт: https://kitaphana-library.nursultanovanurkenze.chatgpt.site

## Сборка

Нужен Node.js.

```sh
npm ci
npm run build
```

Серверный Worker собирается в `dist/server/index.js`. База данных D1: binding `DB`, схема и миграции находятся в `db/` и `drizzle/`.

## Размещение

Сейчас приложение рассчитано на Sites: вход через ChatGPT и доверенные заголовки идентификации устанавливает платформа. Сервер самостоятельно проверяет полномочия администратора. Переменная `LIBRARY_ADMIN_EMAIL` задаётся только как секрет в настройках размещения.

GitHub хранит эту копию кода. GitHub Pages не запускает серверный Worker, D1 и вход в аккаунт: загрузка этих файлов в Pages не перенесёт полноценную библиотеку. При смене хостинга необходимо настроить базу и заменить или безопасно подключить авторизацию; нельзя доверять заголовкам пользователя из открытого интернета.

В этой копии нет базы пользователей, писем, очков, серверных секретов и Git-истории. Это копия исходников, а не резервная копия пользовательских данных.

## Проверки безопасности

Проверены на локальной изолированной базе: отказ обычному пользователю в доступе к admin.html и административным API, игнорирование поддельных полей admin/isAdmin/points, серверный подсчёт результата теста, проверка Origin и необходимость входа для просмотра сообщений. Это не полный аудит безопасности и не гарантия отсутствия уязвимостей.
